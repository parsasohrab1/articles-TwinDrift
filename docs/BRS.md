# Business Requirements Specification – TwinDrift

| ID | Requirement |
|----|-------------|
| BR-1 | Raise an alarm when the behaviour of an asset departs from its healthy digital-twin reference. |
| BR-2 | Set the alarm threshold from healthy data so that the false-alarm rate is controlled. |
| BR-3 | Work with several operating conditions (the reference must be conditional on the operating point). |
| BR-4 | Report the lead time before failure and the share of engines missed; state that the data are simulated. |

Out of scope: field data, root-cause diagnosis, RUL regression, deployment.
